# Student Management Portal

A responsive Student Management Portal built using React and Vite. This application allows users to add student details and view them in a structured table format. It demonstrates React fundamentals such as state management, event handling, form processing, conditional rendering, and component-based UI development.

## Features

* Add new student records
* Input validation for required fields
* Display student data in a dynamic table
* Responsive user interface
* Navigation menu
* Hero section and information cards
* Learning resources section
* Real-time state updates using React Hooks

## Technologies Used

* React.js
* Vite
* JavaScript (ES6+)
* HTML5
* CSS3

## Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/student-management-portal.git
```

### Navigate to Project Directory

```bash
cd student-management-portal
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will run locally at:

```text
http://localhost:5173
```

## Application Functionality

### Add Student

Users can enter:

* Student Name
* Age
* Course

After clicking the **Add Student** button:

* Validation checks whether all fields are filled.
* Student information is stored in React state.
* Data is displayed instantly in the Student Records table.

### Student Records Table

Displays:

| Name         | Age | Course |
| ------------ | --- | ------ |
| Student Name | Age | Course |

Records are updated dynamically without refreshing the page.
